# RAZEY

## 개요

시냅스 없이 마우스 배터리 모니터링 하려고 만든거  

주의 : 개인적으로 쓸 Viper V3 Pro SE 모니터링 하려고 만든거  
다른 마우스 작동 안될거고. 1000hz 동글로만. 8K 동글은 있는데 안써서 안 만듦.  

### 사용 방법

릴리즈 페이지 가면 .exe 파일 있음  
직접 코드들 보고 직접 빌드해서 써도 됨.

## 기능

### 잔량 표시

작긴 한데 대충 잔량 아이콘에 보이긴 해요.
커서 올려놓으면 잔량 뜹니다

### 배터리 경고

완충 알림, 15%, 5%에서 부족 알림 나갑니다.

### 시작 프로그램 등록

알아서 시작 프로그램에 등록합니다.
근데 잔량 아이콘 우클릭 하고 끄기 하면 시작 프로그램에서 해제됨

## 제거

razey_cleanup.bat 파일 실행하고,
exe 파일 제거하면 됨

시작 프로그램 등록 해제하는 스크립트에요.
